# ClarityIQ – Smart Data Cleaning & Analysis Tool

ClarityIQ is a Python-based web application that helps users upload, explore, clean, and analyze datasets through a simple and interactive interface.

## 🚀 Features

* Upload CSV, Excel, JSON, and TSV files.
* Preview uploaded datasets.
* View key data statistics and KPI metrics.
* Explore data using interactive charts.
* Generate data quality reports.
* Check column data types.
* Clean datasets using available cleaning options.
* Compare data before and after cleaning.
* Download cleaned data as a CSV file.

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* OpenPyXL
* xlrd

## ▶️ Run Locally

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python -m streamlit run app.py
```

## 🎯 Project Goal

The goal of ClarityIQ is to make basic data cleaning and exploratory data analysis easier through a user-friendly web application.
